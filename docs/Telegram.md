# Запуск в Telegram (Mini App)

**Сейчас игра живёт на GitHub Pages: https://tevakaraka.github.io/senokos/ — кнопка «Играть» в @Sayilyk_Bot ведёт туда, Мак и туннель не нужны. Обновить игру: `npm run deploy`.**

Ниже — запасной путь через временный туннель с Мака.

Mini App открывается только по https. Пока игра не выложена на хостинг, https даёт
временный туннель Cloudflare: адрес работает, пока Мак включён и туннель запущен,
и меняется при каждом запуске.

## 1. Сервер игры

```bash
cd ~/Desktop/"МОИ ПРОЕКТЫ"/senokos && npm run build && npm run preview
```

## 2. Туннель (в отдельной вкладке терминала)

```bash
cloudflared tunnel --no-autoupdate --url http://localhost:4173
```

Через несколько секунд в выводе появится адрес вида `https://слова-через-дефис.trycloudflare.com`.
LuLu при первом запуске спросит разрешение для `cloudflared` — разрешить.

## 3. Кнопка «Играть» в боте @Sayilyk_Bot

Бот уже создан, токен лежит в `.env.local` (не в git). После запуска туннеля:

```bash
node tools/telegram-bot.mjs setup https://<адрес-туннеля>.trycloudflare.com
```

В чате с ботом слева от поля ввода появится кнопка «Играть» — она открывает игру как Mini App.
Проверить настройку: `node tools/telegram-bot.mjs info`.

## Бот через BotFather (вместо шага 3, если нужна ссылка t.me/…/senokos)

1. Telegram → @BotFather → `/newbot` → имя и логин бота (логин заканчивается на `bot`).
   Токен, который пришлёт BotFather, никому не показывать.
2. `/newapp` → выбрать бота → название «Сенокос», описание, картинка 640×360 (можно любую) →
   вставить https-адрес из шага 2 → короткое имя `senokos`.
3. Игра открывается по ссылке `https://t.me/<логин_бота>/senokos`.

## Если адрес туннеля сменился

@BotFather → `/myapps` → бот → «Сенокос» → Edit Web App URL → новый адрес.

## Что делает игра внутри Telegram

Отключает свайп вниз (окно не сворачивается, когда водишь пальцем), полный экран,
вибрация на взмахе (работает и на iPhone), пауза при сворачивании, подтверждение при закрытии.
Код — `src/platform/platform.ts`. На обычном сайте ничего из этого не загружается.
