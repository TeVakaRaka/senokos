# Сенокос — прототип одного дня

Казуальная игра про сенокос: ведёшь косаря одним пальцем, коса бьёт сама раз в секунду.
Готово: косьба, сушка сена на месте, грабли и тюк, стог, улучшения, итоги дня; коса и грабли —
отдельные инструменты с кнопкой; PvP против бота и с друзьями по сети, до четырёх игроков
(свой стог у каждого, коса подрезает ноги, тюк прикрывает того, кто с граблями, граблями можно
таскать сено из чужого стога). Погода — дальше.

Игра в сети: https://tevakaraka.github.io/senokos/ · в Telegram: @Sayilyk_Bot, кнопка «Играть».

## Запуск

```bash
npm run dev        # для разработки: http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # собранная версия, видна в Wi-Fi: http://<адрес Мака>:4173
npm run host       # сборка и сервер для игры с друзьями: тот же адрес, кнопка «С друзьями»
npm run deploy     # тесты, сборка и публикация на GitHub Pages
```

Игра с друзьями: `npm run host` на компьютере, все открывают в том же Wi-Fi адрес, который он
напечатает, и нажимают «С друзьями»; первый в комнате начинает игру. Сервер только раздаёт игру
и пересылает ввод — считает каждая копия игры сама. Из другого места — через временный туннель:
`cloudflared tunnel --no-autoupdate --url http://localhost:4173` (управление будет запаздывать:
ввод идёт через этот компьютер).

Параметры адреса: `?mode=solo|pvp|net` — один, против бота или по сети, `?room=имя` — комната,
`?go=1` — сразу в игру без заставки,
`?seed=7` — зерно поля, `?look=a|b|c` — вид травы, `?auto=1` — за игрока играет бот,
`?debug=1` — ползунки баланса, `?q=low` — простая картинка, `?selftest=1` — проверка расчётов на устройстве.

Управление: палец (или WASD / стрелки) — куда идти; кнопка справа внизу (или пробел) — коса ↔ грабли.

## Проверки

```bash
npm test           # правила, одинаковость, чистота симуляции
npm run typecheck  # типы
npm run xengine    # одинаковые хеши в V8 (Android) и JavaScriptCore (iPhone), в одиночку и вдвоём
npm run bot        # бот играет день на 20 зёрнах, печатает статистику
npm run bot -- 30 pvp   # два бота друг против друга на 30 зёрнах
```

## Устройство

- `src/sim/` — симуляция без браузера, шаг 1/30 с. Только математика, одинаковая во всех движках
  (см. `dmath.ts`); это проверяет `tests/purity.test.ts`.
- `src/net/` — игра по сети «шаг в шаг»: учёт ввода (`lockstep.ts`) и связь с сервером (`link.ts`).
  Сам сервер — `tools/server.mjs` (без сторонних пакетов).
- `src/render/` — картинка на three.js. `look.ts` — варианты внешнего вида.
- `src/ui/`, `src/audio/` — управление, интерфейс, звук.
- Все числа баланса — в `src/sim/tuning.ts`.
