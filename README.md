# Сенокос — прототип одного дня

Казуальная игра про сенокос: ведёшь косаря одним пальцем, коса бьёт сама раз в секунду.
Готовы шаги 1–2 плана: косьба, сушка сена на месте, грабли и тюк, стог, улучшения, итоги дня.
Погода, игра по сети и PvP — дальше.

Игра в сети: https://tevakaraka.github.io/senokos/ · в Telegram: @Sayilyk_Bot, кнопка «Играть».

## Запуск

```bash
npm run dev        # для разработки: http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # собранная версия, видна в Wi-Fi: http://<адрес Мака>:4173
npm run deploy     # тесты, сборка и публикация на GitHub Pages
```

Параметры адреса: `?seed=7` — зерно поля, `?look=a|b|c` — вид травы, `?auto=1` — играет бот,
`?debug=1` — ползунки баланса, `?q=low` — простая картинка, `?selftest=1` — проверка расчётов на устройстве.

## Проверки

```bash
npm test           # правила, одинаковость, чистота симуляции
npm run typecheck  # типы
npm run xengine    # одинаковые хеши в V8 (Android) и JavaScriptCore (iPhone)
npm run bot        # бот играет день на 20 зёрнах, печатает статистику
```

## Устройство

- `src/sim/` — симуляция без браузера, шаг 1/30 с. Только математика, одинаковая во всех движках
  (см. `dmath.ts`); это проверяет `tests/purity.test.ts`.
- `src/render/` — картинка на three.js. `look.ts` — варианты внешнего вида.
- `src/ui/`, `src/audio/` — управление, интерфейс, звук.
- Все числа баланса — в `src/sim/tuning.ts`.
