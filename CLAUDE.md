# Сенокос — правила проекта

Казуальная веб-игра про сенокос: косарь идёт за пальцем, коса бьёт сама раз в секунду.
Сеттинг нейтральный: без лора «Сайылыка» и якутских терминов.

План и принятые решения — `docs/План прототипа.md`. Готов шаг 1 (косьба, картинка, управление).
Следующий — шаг 2: кучки, сушка, сбор, охапка, стог, первые перки.

## Нельзя нарушать

- **Симуляция считает одинаково на любом устройстве.** В `src/sim/` разрешены только `+ − × ÷ %`
  и `Math.sqrt floor ceil round trunc abs sign min max imul fround`. Никаких `Math.sin/cos/random`,
  оператора `**`, часов и браузера. Синус и косинус — из `dmath.ts`. Это проверяет
  `tests/purity.test.ts`. После любой правки симуляции — `npm test` и `npm run xengine`.
- TypeScript только «стираемый» (без `enum`), импорты с расширением `.ts`: Node запускает
  `src/sim` напрямую, без сборки.
- Набор чисел баланса (`tuning.ts`) замораживается на старте забега. Новое число баланса
  обязательно добавить в `tuningValues()`, иначе оно не попадёт в хеш записи.
- Число и места кустиков — правила игры. Уровни качества меняют только картинку.
- События шага (`swing`, `cutIdx`) в хеш состояния не входят.
- Коммиты — только по команде автора.
- Интерфейс и комментарии в коде — на русском.

## Команды

```bash
npm run dev        # http://localhost:5173
npm run build && npm run preview   # собранная версия в Wi-Fi, порт 4173
npm test           # правила, одинаковость, чистота
npm run typecheck
npm run xengine    # V8 против JavaScriptCore
npm run bot        # статистика бота по зёрнам
```

## Подводные камни

- Системный `jsc` не открывает файлы по пути с кириллицей («МОИ ПРОЕКТЫ»), поэтому
  `tools/xengine.mjs` запускает его из папки `dist-sim/` с одним именем файла.
- Проверка картинки в панели браузера: `window.senokos.freeze(true)`, затем `advance(n)` или
  `advanceToSwing(n)`. Так кадры идут и при скрытой панели, где `requestAnimationFrame` стоит.
  Координаты `zoom` там — в пикселях скриншота (750×1624 при окне 375×812).
- В `ffmpeg` на этом Маке нет фильтра `drawtext`.
- Звуки в `public/audio/` взяты из библиотеки автора; перед публикацией проверить права.
